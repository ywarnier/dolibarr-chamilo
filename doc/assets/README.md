# Screenshots

The images of the guides. They show **fictional demo data** (families, students, a class, rooms, jobs) on a development instance, with the interface in English. The Chamilo address and every key or token were replaced before the capture: never publish an image of the MCP server page or of the setup page without checking that no secret shows.

To retake them after a change of screen: load demo data on a test instance, open each page with a headless browser at a width of 1280 pixels, replace anything secret, save a PNG here under the same name, and remove the demo data.
